# vx-m-open

跨平台微信多开与实例管理工具（开发中）。不修改微信本体、不注入、不碰网络协议。

> 非官方第三方工具，与腾讯官方无关。仅供个人多账号管理使用，请遵守《微信软件许可及服务协议》，使用风险自负。

## 多开原理

| 平台 | 原理 | 是否修改微信本体 |
| --- | --- | --- |
| macOS | 微信 4.x 的单实例限制是沙盒容器内的 `app_data/lock/lock.ini` 文件锁，容器路径由 Bundle ID 决定。工具自动克隆 App 并修改 Bundle ID + 重签名，副本落入独立容器 → 独立锁 → 与主程序共存 | 否（仅副本） |
| Windows | 微信以命名互斥体限制单开。启动时挂起进程，恢复执行后立即轮询并关闭单实例互斥体句柄，微信将认为自己第一个启动，从而多开；直接多开微信本体，不产生副本文件 | 否 |

- macOS 方案已于 2026-10-20 在微信 4.1.15 实测验证
- Windows 方案支持微信 3.x（WeChat.exe）与 4.x（Weixin.exe），自动识别注册表安装路径

## 功能

流程：**创建副本 → 启动副本**，全部在「实例管理」一页完成。

- 环境检测：微信安装路径与版本识别
- 创建副本：输入自定义名字（如"工作号"），APFS 克隆 + 改 Bundle ID + 重签名，约 10 秒；名字同步显示在 Finder / 启动台 / Dock
- 启动 / 关闭 / 激活：每个实例行内操作，实时显示运行状态（PID / 启动时间）
- 改名：副本改名同步更新系统显示名（账号数据不受影响）；主程序支持工具内备注名
- 删除副本：移到废纸篓可恢复，账号数据保留在独立容器中
- 版本同步（v0.3）：微信升级后提示一键重建副本
- Windows：主程序卡片一键「启动新实例」（每点一次多开一个），下方列出运行中的实例（激活 / 关闭）

## 开发

```bash
pnpm install
pnpm tauri dev    # 开发模式（热重载）
pnpm tauri build  # 打包 dmg / msi
```

技术栈：Tauri 2 + Rust + Vue 3 + TypeScript + Pinia。
